## Разделение данных до моделирования

До любых преобразований данные делятся на три непересекающиеся части с
фиксированным `random_state=42`:

| Выборка     |                          Доля | Назначение                                                          |
| ----------- | ----------------------------: | ------------------------------------------------------------------- |
| Обучающая   | 60 % (примерно 95 наблюдений) | Обучение модели и оценка параметров преобразований.                 |
| Проверочная | 20 % (примерно 32 наблюдения) | Выбор признаков, настройка гиперпараметров и выбор варианта модели. |
| Тестовая    | 20 % (примерно 32 наблюдения) | Однократная итоговая оценка выбранной модели.                       |

Для сохранения представительства видов рыб разбиение выполняется с
разделением по `Species`.

Все параметры, зависящие от данных, рассчитываются только на обучающей выборке:
масштабирование, кодирование категорий, заполнение пропусков и отбор признаков. Затем те же уже обученные преобразования применяются к
проверочной и тестовой выборкам. Тестовая выборка не используется для выбора
модели или её настроек.

## Возможные каналы утечки данных

| Канал утечки                      | Как возникает                                                                                                                  | Последствие                                                                                      | Предотвращение                                                                                                    |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| Статистики всей таблицы           | Среднее, медиана, границы выбросов, параметры масштабирования или заполнения пропусков вычислены до разбиения по всем строкам. | Модель косвенно получает сведения о проверочной и тестовой выборках; метрики завышаются.         | Обучать все преобразования только на обучающей части и применять их к остальным частям без переобучения.          |
| Повторные строки                  | Одинаковые или почти одинаковые наблюдения оказываются одновременно в обучающей и тестовой частях.                             | Модель фактически встречает тестовый объект при обучении.                                        | Проверить дубликаты до разбиения; связанные дубликаты держать в одной части или удалить по обоснованному правилу. |
| Идентификатор                     | В признаки включён номер записи, идентификатор партии, файла или иной технический ключ, связанный с целевой переменной.        | Модель запоминает происхождение записи вместо закономерности.                                    | Исключать технические идентификаторы из признаков; применять их только для группового разбиения.                  |
| Постфактум измерение              | Используется величина, доступная только после взвешивания или после наступления прогнозируемого события.                       | При реальном применении признак недоступен, а качество офлайн-оценки оказывается нереалистичным. | Для каждого признака фиксировать момент его получения и оставлять только доступные до прогноза данные.            |
| Ручной подбор по тестовой выборке | Признаки, алгоритм или гиперпараметры  многократно меняются после просмотра тестовых метрик.                            | Тестовая выборка превращается в проверочную, итоговая оценка теряет независимость.               | Принимать решения по проверочной выборке; тестовую использовать один раз после фиксации решения.                  |
