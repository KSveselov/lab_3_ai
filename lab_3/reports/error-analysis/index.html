Шесть галерей ошибок E2

Зелёный — эталон, красный — модель. IoU — пересечение рамок / их объединение.

По одному событию на кадр, до четырёх кадров на категорию. Категории могут пересекаться.

  • 1. Ложные срабатывания с высокой уверенностью

    Нет сопоставленного эталона, уверенность ≥ 0.75.

  • 2. Пропуски критичного класса — без каски

    Для эталона NO-Hardhat нет ответа того же класса с IoU ≥ 0.5.

  • 3. Сопоставленные рамки с низким IoU

    Класс совпал, но 0.5 ≤ IoU < 0.75: рамка локализована неточно.

  • 4. Путаница похожих классов

    IoU ≥ 0.5 у несопоставленных рамок похожих, но разных классов.

  • 5. Малые и потенциально перекрытые объекты

    Площадь < 0.25% кадра или перекрытие рамкой того же класса ≥ 50%; есть пропуск или низкий IoU. Перекрытие требует ручной проверки.

  • 6. Предположительные ошибки разметки

    Уверенность ≥ 0.85, IoU со всеми эталонами < 0.1. Это подозрение, а не доказанная ошибка разметки.
