# Паспорта моделей E0–E4

## Общие сведения

- Задача: предсказать массу рыбы `Weight` в граммах.
- Данные: `fish_participant.csv`.
- Разделение: 79.28% для обучения и 20.72% для тестирования, `seed = 42`.
- Общие признаки: `Length3`, `Height`, `Width`, `Species`.
- Для E1–E4 числовые признаки заполняются медианой и масштабируются, а `Species`
  кодируется One-Hot Encoder. Неизвестный вид не приводит к ошибке.
- MSE измеряется в г², MAE — в граммах. Меньшие MSE и MAE лучше, больший R² лучше.

## E0 — константный baseline

### Назначение

Показывает минимальный ориентир качества: модель не использует признаки и всегда
возвращает одну и ту же массу.

### Версии

- `E0-mean`: среднее значение `Weight` на обучающей выборке.
- `E0-median`: медиана `Weight` на обучающей выборке.

### Качество и вывод

Медиана немного лучше по MAE (238.24 г), но обе версии имеют отрицательный R².
Они заметно хуже моделей E1–E4 и нужны только как честная точка сравнения.

### Ограничения

Не учитываются вид и размеры рыбы, поэтому прогноз одинаков для всех объектов.

## E1 — линейная регрессия

### Модель и признаки

`LinearRegression` использует `Length3`, `Height`, `Width` и `Species`.

### Качество

- Test MAE: 74.54 г;
- Test MSE: 7825.40 г²;
- Test R²: 0.925;
- CV MSE: 16459.48 ± 12953.71 г²;
- отрицательных прогнозов: 3.

### Ограничения и вывод

Линейная зависимость недостаточно хорошо описывает массу рыб разных размеров и
видов. Отрицательные прогнозы физически невозможны, поэтому модель нельзя
выбирать для итогового решения.

## E2 — Ridge-регрессия

### Модель и признаки

`Ridge(alpha=1)` использует те же признаки, что и E1. Регуляризация уменьшает
влияние коррелирующих признаков, но сохраняет линейную форму модели.

### Качество

- Test MAE: 73.84 г;
- Test MSE: 8053.05 г²;
- Test R²: 0.923;
- CV MSE: 14460.84 ± 10007.82 г²;
- отрицательных прогнозов: 3.

### Ограничения и вывод

Ridge немного улучшает MAE относительно E1, однако отрицательные прогнозы
остаются. Линейной модели недостаточно для учёта нелинейной связи размеров и
массы.

## E3 — Random Forest

### Модель и признаки

`RandomForestRegressor` с `n_estimators=300`, `max_depth=None` и
`min_samples_leaf=1`. Использует базовые признаки `Length3`, `Height`, `Width`
и `Species`.

### Качество

- Test MAE: 37.79 г;
- Test MSE: 3469.70 г²;
- Test R²: 0.967;
- CV MSE: 9449.81 ± 11100.90 г²;
- отрицательных прогнозов: 0.

### Ограничения и вывод

Модель значительно превосходит линейные варианты и не создаёт физически
невозможных прогнозов. Большое стандартное отклонение CV MSE показывает, что
качество зависит от состава фолдов; данных для отдельных видов немного.

## E4-A — Random Forest с базовыми признаками

### Назначение

Контрольная версия эксперимента E4. Архитектура и признаки совпадают с E3, чтобы
сравнение с добавлением `Vproxy` было честным.

### Качество и вывод

Метрики совпали с E3: Test MAE 37.79 г, Test R² 0.967, отрицательных прогнозов
нет. Эта версия служит baseline для E4-B.

## E4-B — Random Forest с Vproxy

### Модель и признаки

Та же конфигурация Random Forest, что в E4-A, но добавлен признак
`Vproxy = Length3 × Height × Width`. Он приближённо описывает объём рыбы.

### Качество

- Test MAE: 34.37 г;
- Test MSE: 2503.42 г²;
- Test R²: 0.976;
- CV MSE: 9278.21 ± 10180.41 г²;
- отрицательных, неположительных и нечисловых прогнозов: 0.

### Анализ ошибок

Ошибка зависит от размера: MAE составляет 7.74 г для маленьких рыб, 25.73 г для
средних и 68.57 г для крупных. Наиболее сложные виды по MAE: Roach (57.45 г),
Pike (49.03 г) и Bream (45.59 г). Для редких видов оценка нестабильна, поскольку
в тестовой выборке мало наблюдений.

### Ограничения

Модель применима только к диапазонам размеров и видам, представленным в
обучающих данных. Для крупных рыб ошибка выше, а высокая CV-нестабильность
требует осторожной интерпретации качества.

### Рекомендация

Выбрать E4-B как итоговую модель. Следующий эксперимент: обучить отдельные
модели по видам и сравнить их с общей E4-B по MAE. Ожидаемый результат —
снижение ошибки для Bream, Pike и Roach.
