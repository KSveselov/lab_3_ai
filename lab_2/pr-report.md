# Лабораторная работа №2: регрессионная модель массы рыбы и MLflow

## Описание

Построены и сравнены модели прогнозирования массы рыбы по виду и измерениям
тела. Выбор итоговой модели выполняется по средней квадратичной ошибке
кросс-валидации на обучающей выборке.

- Добавлены эксперименты E0–E4: прогноз среднего и медианы, линейная регрессия,
  Ridge, случайный лес и сравнение леса с производным признаком объёма.
- Зафиксировано стратифицированное по виду разбиение: 88 строк обучения и
  23 строки теста, `random_state=42`. Индексы сохранены в
  `fish_weight_prediction_machine_learning/src/split_indices.json`.
- Предобработка объединена с регрессором в `Pipeline`: заполнение числовых
  пропусков медианой, масштабирование, заполнение категориальных пропусков
  и кодирование видов через `OneHotEncoder(handle_unknown="ignore")`.
- Гиперпараметры Ridge и случайного леса выбираются по пятифолдовой
  кросс-валидации внутри обучающей выборки. Сетки поиска и бюджет описаны
  в отчёте.
- Для E1–E4 сохранены локальные запуски MLflow: параметры, тестовые метрики,
  среднее и стандартное отклонение CV MSE, версии окружения, коммит,
  пайплайны, таблицы прогнозов и графики.
- Выполнен анализ ошибок: пять крупнейших промахов с исходными признаками,
  MAE по видам и диапазонам размеров, проверка физически невозможных
  прогнозов, обсуждение причин и следующего эксперимента.
- Добавлены тесты пайплайна и экспорта отчётов MLflow, инструкции запуска
  и сценарий открытия локального интерфейса MLflow.

### Результаты

Все варианты E0–E4 оценены на одной тестовой выборке. MSE измеряется в г²,
MAE — в граммах. Для ошибок меньшее значение лучше, для R² — большее.

| Эксперимент | Модель | MSE теста, г² | MAE теста, г | R² теста | CV MSE, среднее ± стандартное отклонение, г² |
|---|---|---:|---:|---:|---:|
| E0, среднее | Константа обучения | 106322.94 | 268.49 | -0.021 | — |
| E0, медиана | Константа обучения | 108359.43 | 238.24 | -0.040 | — |
| E1 | Линейная регрессия | 7825.40 | 74.54 | 0.925 | 16459.48 ± 12953.71 |
| E2 | Ridge, alpha = 1 | 8053.05 | 73.84 | 0.923 | 14460.84 ± 10007.82 |
| E3 | Случайный лес | 3469.70 | 37.79 | 0.967 | 9449.81 ± 11100.90 |
| E4-A | Лес, базовые признаки | 3469.70 | 37.79 | 0.967 | 9449.81 ± 11100.90 |
| E4-B | Лес с Vproxy | 2503.42 | 34.37 | 0.976 | 9278.21 ± 10180.41 |

Выбрана E4-B: случайный лес с 300 деревьями и признаком
`Vproxy = Length3 × Height × Width`. По сравнению с E4-A тестовый MSE
снизился на 27.85%, MAE — на 9.03%, средний CV MSE — на 1.82%.
Большой разброс CV не позволяет считать улучшение доказанным для любых
новых данных.

У E4-B на тесте нет отрицательных, нулевых или неконечных прогнозов.
Ошибка растёт с размером рыбы: MAE составляет 7.74, 25.73 и 68.57 г
для трёх диапазонов длины. Крупнейшая ошибка — 134.49 г для плотвы.
Следующий эксперимент: сравнить отдельные модели по видам с общей моделью;
ожидается снижение ошибки для видов с наибольшими промахами при достаточном
числе обучающих наблюдений.

## Использование ИИ

**Инструмент:** Codex.

Оба фрагмента взяты из `tests/test_pipeline.py`. 

**1. Проверка обработки неизвестного вида рыбы:**

```python
def test_pipeline_accepts_unknown_species(trained_model):
    _, test_df = load_data()
    features = NUMERIC_COLUMNS + CATEGORICAL_COLUMNS
    unknown_fish = test_df.loc[:, features].head(1).copy()
    unknown_fish["Species"] = "UnknownFish"

    prediction = trained_model.predict(unknown_fish)

    assert len(prediction) == 1
    assert np.isfinite(prediction).all()
```

Тест создаёт копию входной строки и заменяет вид на отсутствующую в обучении
категорию. Затем проверяет, что пайплайн возвращает один конечный прогноз.
Фикстура `trained_model` обучает линейный пайплайн из `src/e1.py`.

**2. Проверка воспроизводимости после сохранения и загрузки модели:**

```python
def test_saved_pipeline_reproduces_predictions(trained_model, tmp_path):
    _, test_df = load_data()
    features = NUMERIC_COLUMNS + CATEGORICAL_COLUMNS
    input_data = test_df.loc[:, features].head(3)
    expected_prediction = trained_model.predict(input_data)
    model_path = tmp_path / "fish_model.joblib"

    joblib.dump(trained_model, model_path)
    loaded_model = joblib.load(model_path)

    np.testing.assert_allclose(
        loaded_model.predict(input_data), expected_prediction, rtol=1e-8, atol=1e-8
    )
```

Тест вычисляет прогноз для трёх строк, сохраняет пайплайн 
и загружает его обратно. Прогнозы сравниваются с исходными при; `tmp_path` предоставляет временный каталог pytest.

Соответствующие инварианты ранее проверены отдельно: неизвестный вид
принимается, сериализация новой линейной модели в памяти сохраняет
прогноз. Приведённые pytest-тесты не запускались из-за отсутствия pytest
в окружении; совместимость старой E4-B эти проверки не подтверждают.

**Как проверено:** Сопоставлены с документацией pytest.
